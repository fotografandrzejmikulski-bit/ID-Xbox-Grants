## What is project-specific

The following are project targets or planning assumptions unless backed by independent evidence:

- USD 400,000 funding model,
- 12-month delivery schedule,
- 60 FPS target,
- eightteen-person team,
- Unreal Engine 5 stack,
- exact memory/performance budgets,
- accessibility implementation scope,
- proposed launch window,
- pricing and promotion strategy.

## What should not be stated as fact without evidence

- a fixed DAP maximum award,
- guaranteed funding approval,
- guaranteed non-exclusivity unless current terms establish it,
- specific certification check counts,
- exact mandatory pixel sizes or contrast ratios,
- vendor license prices,
- guaranteed storefront placement or algorithmic visibility,
- guaranteed Game Pass placement,
- any causal claim about sales uplift without supporting data.

## Editorial standard

Use one of three labels when drafting internal planning material:

- **CONFIRMED** — directly supported by a current primary source.
- **PROJECT TARGET** — an explicit project goal measured internally.
- **ASSUMPTION / VERIFY** — useful planning hypothesis that must not be presented to Microsoft as established fact.
