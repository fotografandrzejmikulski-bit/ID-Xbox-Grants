# Budget & Funding Case

## Funding principle

The budget is structured around deliverables that remove the project's largest barriers to Xbox release: proof-of-concept completion, platform engineering, QA/certification readiness, and accessibility.

The **USD 400,000 figure is retained only as a planning scenario** inherited from the source application. It is not described as a confirmed DAP ceiling. Current program documentation must be checked before submission.

## Planning budget

| Workstream | Planning allocation (USD) | Primary deliverable |
|---|---:|---|
| Vertical Slice | 100,000 | Playable, representative production-quality slice |
| Xbox platform engineering | 150,000 | Platform services, performance and packaging work |
| QA / certification readiness | 75,000 | Regression, platform test matrix and submission readiness |
| Accessibility | 75,000 | Accessible UI/gameplay implementation and user testing |
| **Planning total** | **400,000** | |

## Cost justification

### Vertical Slice — $100,000 planning envelope

Covers gameplay engineering, design iteration, environment/art integration, audio implementation, narrative integration, tooling, bug fixing and production management required to turn the core concept into a representative build.

### Platform engineering — $150,000 planning envelope

Covers platform-specific engineering, package configuration, service integration where required, performance profiling, memory analysis, save-state implementation, input behavior, error handling and release candidate stabilization.

Microsoft's current publishing documentation shows that technical capabilities and Xbox services are configured in Partner Center, including Xbox Play Anywhere, cloud saves, achievements and other services. ### QA / certification readiness — $75,000 planning envelope

Covers dedicated QA labor, test matrix creation, regression, device coverage, defect triage, release candidate testing and submission preparation. The budget deliberately avoids unsupported claims about a fixed number of certification checks.

### Accessibility — $75,000 planning envelope

Covers accessibility design reviews, implementation, testing with disabled players, UI/input iteration, documentation and regression.

## Budget controls

Before final submission the studio should attach, where available:

- supplier quotations,
- internal rate cards,
- role/day assumptions,
- payroll or contractor assumptions,
- contingency logic,
- milestone-linked cash-flow schedule.

Every funded activity must map to a project outcome. Any line item that cannot be tied to a deliverable should be removed or justified.

## Funding variants

### Minimum viable funding case

Prioritize Vertical Slice + critical platform engineering + essential QA. Defer non-critical enhancements until the funding decision and verified platform scope are known.

### Full funding case

Fund the complete plan above, subject to the verified program cap and eligible-cost rules.
