# Pieśń Zapomnianych — ID@Xbox Grant Package

Repozytorium zawiera roboczy pakiet aplikacyjny i dokumentację projektu „Pieśń Zapomnianych” przygotowaną pod kątem programu ID@Xbox Developer Acceleration Program (DAP).

> **Status:** application package / pre-submission documentation. Claims about program eligibility, grant size, platform requirements, certification terminology and current Xbox policies must be verified against current Microsoft documentation before external submission.

## Cel repozytorium

- utrzymywać główny opis projektu i argumentację grantową,
- dokumentować zakres Vertical Slice,
- dokumentować plan techniczny Xbox Series X|S / Windows,
- prowadzić plan accessibility i QA,
- utrzymywać budżet, harmonogram, ryzyka oraz założenia Go-To-Market,
- oddzielać potwierdzone wymagania platformy od założeń projektowych.

## Struktura

- `docs/application.md` — zrewidowany dokument aplikacyjny,
- `docs/verification-matrix.md` — macierz twierdzeń wymagających weryfikacji źródłowej,
- `docs/production-plan.md` — zakres produkcyjny, milestone'y i kryteria akceptacji,
- `docs/accessibility.md` — plan dostępności i testów, bez przedstawiania niezweryfikowanych wartości liczbowych jako wymagań Microsoftu,
- `docs/budget.md` — budżet grantowy i uzasadnienie kosztów,
- `docs/risk-register.md` — rejestr ryzyk,
- `docs/release-plan.md` — plan wydawniczy i certyfikacyjny,
- `docs/team-and-evidence.md` — lista dowodów, które należy dostarczyć komisji,
- `docs/source-notes.md` — zasady rozróżniania danych potwierdzonych, założeń i hipotez.

## Zasada wiarygodności

Dokument aplikacyjny nie powinien przedstawiać jako faktu żadnego szczegółu, którego nie można poprzeć aktualnym źródłem Microsoft/Xbox albo rzeczywistymi danymi studia. Dotyczy to w szczególności maksymalnej kwoty grantu, kryteriów programu, nazw i numeracji checklist certyfikacyjnych, wymagań pamięci, zasad Xbox Play Anywhere, dostępności, Game Pass oraz harmonogramów akceptacji.

## Projekt

**Tytuł:** Pieśń Zapomnianych  
**Gatunek:** narrative action-RPG / puzzle  
**Core mechanic:** system Harmonii — rytm, muzyka i polifoniczny śpiew jako interfejs walki, nawigacji i zmian środowiska  
**Platform target:** Xbox Series X|S + Windows PC, z zakresem usług platformowych ustalanym dopiero po potwierdzeniu wymagań i kontraktów Microsoft.

## Odpowiedzialne przedstawianie zespołu

Deklaracje dotyczące reprezentacji zespołu, statusu prawnego, liczebności, doświadczenia i kwalifikacji muszą być zgodne z rzeczywistym stanem i możliwe do udokumentowania. Nie należy używać deklaracji tożsamościowych jako substytutu dowodów zdolności produkcyjnej.

## Przed złożeniem

Przed wysłaniem materiałów należy przeprowadzić końcowy fact-check wszystkich twierdzeń oznaczonych w macierzy weryfikacji jako `VERIFY`, a następnie zaktualizować dokument oraz budżet tak, aby kwota i zakres odpowiadały rzeczywistym zasadom programu w momencie aplikowania.
